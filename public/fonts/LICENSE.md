Fonts self-hosted here come from Google Fonts, all under the SIL
Open Font License 1.1 (https://openfontlicense.org):

- Fraunces (https://fonts.google.com/specimen/Fraunces), designed by
  Undercase Type
- JetBrains Mono (https://fonts.google.com/specimen/JetBrains+Mono),
  designed by JetBrains
- Noto Nastaliq Urdu Bold (https://fonts.google.com/noto/specimen/Noto+Nastaliq+Urdu),
  by Google, used only for the header wordmark. It is a subset (about 2.5KB
  instead of 528KB) holding just the glyphs needed to shape the wordmark
  text; see src/content/data/wordmark-font.json for how to regenerate it.

Fraunces and JetBrains Mono are variable fonts; a single file per family
covers the weight range this site uses instead of one static file per weight.
